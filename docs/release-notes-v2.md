# Pluckr 2: release notes (draft)

Use for the site, the Marketplace "what's new" line and a LinkedIn post, once version 3 is live.

## Short (Marketplace / social)

Pluckr 2 adds Google Slides. Pull every picture out of a deck, convert it, rename it in bulk, and add alt text. In Docs you can now export Markdown with an images folder and shrink the images inside the file.

## What's new

- **Google Slides.** Every picture on every slide, including grouped ones. Same sidebar, same one-time $5 for Docs and Slides.
- **Select what you need.** Tick images, then download, convert or rename only those.
- **Bulk rename.** Patterns like `{doc}-{n}` with a live preview.
- **Alt text.** See which images have none, write it in the sidebar, save it to the file, or export it as CSV and JSON.
- **Markdown export (Docs).** A content.md file with the images folder, alt text kept.
- **Optimize.** Shrink the images inside the Doc or deck. Pictures keep their size, alt text and links. Pluckr asks you to confirm and suggests a copy first.
- **A new look.** Light and dark themes.

## One thing to know

Existing users will see one new permission prompt the next time they open Pluckr: access to the open presentation. It is limited to the file you are in, and Pluckr changes the file only when you press Save or confirm Optimize.

## Not included yet

Floating images and images in headers, footers or footnotes in Docs. Images used as shape fills, backgrounds, or on layouts and masters in Slides. Google Sheets.
