Five image checks before you publish

  1. 1
    A file name that says what it isblue-trail-shoes.webp beats IMG_4032.png
  2. 2
    Alt text on every imageDescribe the picture in one plain sentence.
  3. 3
    WebP or AVIF, under 150 KBSmaller images, faster pages, better Core Web Vitals.
  4. 4
    Width that matches the layoutNo 4000 px photos in a 800 px column.
  5. 5
    One keyword, used onceIn the file name or the alt text, never stuffed.
