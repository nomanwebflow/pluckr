# Pluckr

> Pluckr is a Google Docs and Google Slides add-on that extracts every image into a single ZIP file, renames them in bulk, converts them to WebP or AVIF, and exports clean Markdown with an images folder.

Pluckr runs entirely client-side in the browser and Google Apps Script. All image processing, resizing, and format conversions happen locally on the user's computer. Document images and content are never uploaded to external servers.

## Key Features

- **Extract Images in Bulk**: Download all inline images from Google Docs or slide pictures from Google Slides in original resolution as a single ZIP file.
- **Bulk Renaming**: Rename images before downloading using custom base names, counters, prefixes, suffixes, or kebab-case slug patterns.
- **Modern Format Conversion**: Convert images to WebP, AVIF, JPEG, or PNG with configurable compression quality and max dimension limits. Small images are never upscaled.
- **Clean Markdown Export**: Export Google Docs to clean `content.md` with an accompanying `images/` directory, replacing Google Docs' default bloated base64 data URLs.
- **Alt Text Management**: Review, edit, and bulk export image alt text as CSV or JSON.
- **Privacy First**: Zero image uploads. Only a Google identity token is validated against the license check service; image bytes never leave the local environment.
- **Pricing**: Free for up to 50 images per Google account, in total, across all of that account's Docs and decks. An image counts once, the first time it is copied or downloaded. Pro is a one-time payment of $12 for one Google account, with no subscription and a 14-day refund. Pro removes the limit and adds bulk renaming, alt text editing, format conversion, crop and resize, Optimize, Markdown export and Save to Drive.
