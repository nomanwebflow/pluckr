What it does

Find inline images across document tabs, review them, and export originals or optimized copies.

Grab every image

Lists every image in your Doc, including images in tables and nested tabs, or every picture on your Slides deck, including grouped ones.

Compress & resize

Choose an output format, adjust quality for lossy formats, and set an optional maximum width in pixels.

Convert formats

Convert to AVIF, WebP, JPEG, or PNG. Image drawing and conversion run locally in a background worker.

Pick & bundle

See each image’s preview, dimensions, and file size. Tick the ones you want, rename them in bulk, then copy, download, or export a ZIP.

Private by design

Pluckr has no separate image server. Google Apps Script reads images from the open Doc or deck; conversions run in your browser.

Alt text & Markdown

See which images have no alt text and write it in the sidebar. In Docs, export the text as Markdown with an images folder.

How it works

Open Pluckr from Google Docs, review the images, then download originals or convert and export.

01

Open Pluckr in Docs or Slides

In a Google Doc, choose Extensions → Pluckr → Extract images. The Pluckr sidebar opens beside your document.

02

Authorize document access

Review Pluckr’s data-use notice, then choose to scan. Approve access to the current document when Google asks; Pluckr reads embedded inline images, including content in nested tabs.

03

Scan the document

Pluckr lists inline images from the document body with a preview, filename, dimensions, and file size. Images in tables are included; floating images and images in headers, footers, or footnotes are not.

04

Set format & quality

Choose AVIF, WebP, JPEG, or PNG, adjust quality where available, and optionally set a maximum width in pixels.

05

Convert & download

Convert images in the sidebar and download each result, or export the converted set as a ZIP. You can also download the original images together.
